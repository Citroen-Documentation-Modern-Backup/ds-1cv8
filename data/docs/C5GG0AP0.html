C5GG0AP0Dépose - repose : Nappe chauffante de dossier de siège avant
SIEGE CHAUFFANT
1. Outillage préconisé
Figure : e5-p12yc
[ 1] pince à agrafer.
Figure : e5-p12zc
[ 2] couteau à mastic.
2. Dépose
IMPERATIF : Lorsque le véhicule est équipé d’un système pyrotechnique : Respecter les consignes de sécurité.
Déposer le siège (voir opération correspondante).
Placer le siège sur un établi propre.
Déposer les caches latéraux.
Figure : c5gp01qc
Décrocher les 2 élastiques (1) de maintien de la garniture.
Débrancher les connecteurs (2).
Basculer les crochets ( 3) (suivant flèche ).
Déposer l’assise.
Déposer les guides de appui-tête ( 4), rotation d’un 1/2 tour et soulever (suivant flèches).
Figure : c5gp01rc
Décrocher :
  • La garniture de dossier ( 5), sur 3 côtés
  • La garniture arrière de dossier (6), latéralement
Figure : c5gp01tc
Basculer la garniture arrière du dossier.
Couper les agrafes (7).
Décrocher la garniture arrière de la barre de maintien ( 8).
Figure : c5gp01sc
Retourner le siège.
Déposer la garniture de dossier ( 5), avec la mousse (9).
Figure : c5gp01uc
Basculer la garniture, vers l’arrière.
Décoller soigneusement la nappe chauffante ( 10) (à l’aide d’un cutter).
3. Repose
NOTA : Les nappes chauffantes sont préencollées.
Poser :
  • Une nappe chauffante ( 10)
  • La mousse (9) avec la garniture de dossier (5)
Figure : c5gp01vc
ATTENTION : Prendre soin de ne pas agrafer la nappe chauffante.
Agrafer la garniture de dossier À l’aide de l’outil [1].
Figure : c5gp01wc
Accrocher :
  • La garniture arrière sur la barre de maintien ( 8)
  • La garniture arrière de dossier (6), latéralement À l’aide de l’outil [2]
  • La garniture de dossier (5), sur 3 côtés
Figure : c5gp01xc
Reposer les guides de appui-tête ( 4).
Orienter les encoches " a" vers l’arrière du siège et emboîter à fond les guides de appui-tête.
Reposer l’assise du siège.
Accrocher les 2 élastiques (1) de maintien de la garniture.
Rebrancher les connecteurs (2).
Basculer les crochets ( 3).
Reposer les caches latéraux.
Reposer le siège.
